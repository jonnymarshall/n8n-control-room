# ItemStatus

_The publishing state of an item._

## Values

- `DRAFT` — A work-in-progress item, not yet in the feed.
- `SCHEDULED` — Set to publish automatically at a future time.
- `PUBLISHED` — Live in the feed.
- `ERROR` — Publishing failed.
- `DELETED` — Soft-deleted and removed from the feed.

## Example

```json
PUBLISHED
```
