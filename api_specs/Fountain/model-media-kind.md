# MediaKind

_The kind of media an upload holds._

## Values

- `FEED_IMAGE` — A feed's cover artwork.
- `ITEM_IMAGE` — An item's cover artwork.
- `ITEM_AUDIO` — An item's audio enclosure.
- `ITEM_VIDEO` — An item's video enclosure, transcoded to HLS.
- `SOCIAL_POST_VIDEO` — A video attached to a social post.

## Example

```json
ITEM_AUDIO
```
